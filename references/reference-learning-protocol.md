# Detailed reference learning: evidence → rules → application → checks

用户偏好，2026-10-25：以后学习都遵循最初约定的细致流程，可以在相关且获授权时深入。学习是修改可复用工作流，不是训练模型权重。不得用“高级、专业、美观”或图型清单代替逐图证据。

## 1. Scope and source inventory

- 从现有记录接续：先查 `sources.md` 与本次问题相关的条目，再读对应图型规则；仅为核对细节打开 dated 记录。已经读过且未改变的内容不重复整篇加载。将当前范围、完成项、证据版本、阻碍和下一步保存在现有学习记录，不另造进度文件。
- 自主发现新参考时，先确定一个尚未解决的表达问题，再按数据适配性、能否看见图和图注、是否提供新设计机制筛选；同一 DOI + 版本 + 图号先去重。默认一批细读至多两张新图，明确任务要求更大范围时按清单分批；用户上传的一组图仍须覆盖其全部请求范围。
- 先区分参考学习、实际出图、已有图修订。参考学习不要求安装依赖、重跑原研究或制作新图；实际出图按当前授权选择 RStudio 执行保存的 R 代码，或使用 Origin 原生项目，并检查实际结果。
- 读取现有 skill 和本任务相关资源；备份拟修改文件，合并到已有规则，不另建相互矛盾的流程。保留无关个人配置及历史记录。
- 建来源清单：用户图片编号/文件名，或论文标题、真实刊物名、版本、URL、图号；查阅日期；PDF 同时记物理页序号和印刷页码，必要时记校验和。区分期刊官方要求与作者设计选择。
- 明确本批范围。用户给出一组图或整篇论文时，先索引全部图，再逐项完成；若需分批，列出已读与尚未读，不把部分当作全覆盖。
- 图像、图注与解释关键变量的邻近段落一起读。PDF 先看完整页面和排版，再放大密集区域；OCR/文字提取不能替代实际看图。不可访问的资料标为“仅图注/仅摘要/未查看”，不编造观察。
- 仅记录设计摘要、出处和必要元数据；没有额外授权不复制原图、原始数据、大段文字或独特构图。私人资料不发送到 dsh/其他外部服务；公共检索分工见 [assisted-journal-learning.md](assisted-journal-learning.md)。

把“找候选”和“细读选中图”分开：先保留来源、图号、可访问状态和可能解决的问题；筛选后才请求必要截图/图注并做八项细读。已有明确图链接或用户图像时跳过广泛搜索。已有可读原图无需再制作拼接阅读页；小范围放大只用于解决具体密集或含义不明之处。不可访问项标记原因，可用公开作者/机构副本须注明版本；不反复请求同一受限地址或把检索摘要升级成已看图。

## 2. One evidence card per figure

以下每项必须有具体观察、明确未知，或说明“不适用”的原因。复杂多面板图逐面板补充，不用一段笼统概括。采用四种证据标签：**可见**（实际读图）、**文述**（图注/方法声称）、**建议**（拟迁移设计）、**待核验**（证据不足）；文述不等于已验证。

1. **问题与图型**：数据结构、图表类型、表达目的和适用任务；每个面板是现象、分布、估计、不确定性、验证还是局限；为何需要该编码，有无更直接替代。
2. **层级与版面**：主次信息、阅读方向、面板比例/顺序、对齐基准、留白用途、图例与色标占位；对照图哪些条件保持一致。能测量时记方法与单位，不能测量时只述相对关系。
3. **字体与线条**：标题/标签/坐标/图例/说明的相对层级；数据线、网格、参考线和边框的强弱；点形、大小、实空心、端帽、箭头、透明度。只凭截图不猜原字体、pt 字号、线宽或精确 alpha。
4. **配色逻辑**：色相数量及角色，明度/饱和度层级，背景/重点/辅助色，分类/顺序/发散/循环/强调的语义；重复变量是否同色；叠加与缺测颜色。截图色值不是原始样式；实测像素要标明是压缩/混色后的样本，不能冒充原 HEX。
5. **标注与图例**：共享或分面图例、直接标签、引线、符号、编号、数学表达和阈值；有无遮挡、重复、未解释图层、图例与标记不一致；流程箭头是数据流、因果关系还是假设。
6. **坐标与科学完整性**：变量、单位、范围、零点/中心、刻度间距、对数/归一化、排序、分母、缺失/裁切/插值；数据来源、样本量、独立重复、区间定义、统计方法、显著性标记及适用限制。对示意图记坐标/比例“不适用”或“示意”，但仍核查连接、角度、尺寸及符号定义。无误差线不等于无误差；无星号不需人为添加。
7. **文件与缩放**：实际已知的像素、PDF 放置毫米尺寸、位图/矢量结构、源字号/字体信息；区分源数据与本次阅读渲染参数。检查整图、最小标签及密集区；屏幕放大可读不等于最终刊载尺寸可读。没有原文件则导出设置、字体嵌入等标未知。
8. **迁移决策**：分别写“采用/调整/不采用”，说明适用条件和证据，映射到配置项、绘图层或 QA 断言；明确哪些仅适用于此图。记录至少一个有根据的正向设计机制；若没有值得迁移之处，说明原因而非强行赞美。问题清单不能代替设计学习。

## 3. Cross-figure synthesis and executable transfer

- 每条拟新增规则先与现有图型文件比对，判为新增、加深、重复或冲突；重复只补来源，冲突明确裁决，新增/加深写进原有指南。每条有用增量包含：输入数据条件 → 为什么选择该图 → 不适用情形 → R 配置/图层位置 → 将来实际验收的方法。不得把“看过一个新图”自动变成增加一个通用文件。
- 先找跨图重复的规律，再提炼特定图型规则。一个参考的颜色、布局或全部图型都不是通用模板；多元意味着按问题选互补表达，不是强迫每张图都不同。
- 按“观察 → 作用机制 → 适用边界 → R 实现位置 → 验收证据”转换，保留不采用的反例。若与旧规则冲突，优先科学正确性、用户要求和经核实的投稿要求；说明取舍，不覆盖有效旧内容。
- 对应真实现有配置与代码；代码没有读取的新字段只算拟议参数，不能称为已实现。旧示例的布局、透明度或中心值若写死，应在新项目中移入配置并绑定对应图层。具体例子见 [engineering-model-figures.md](engineering-model-figures.md)。
- 样式起始值是设计建议，不是从参考图“测得”的数值或期刊标准。图区尺寸、字号、线宽、配色、间距、坐标范围及导出分别可调；处理过程与外观分离。
- 如需新色板，按 [色卡库的收录流程](palette-library.md) 命名、去重并登记为候选，更新可浏览色卡；明确原始标注色值、像素近似或重新设计的提案，不把截图推断当作精确原色。复用 [palette-system.md](palette-system.md) 的分类库和命名映射；保存 HEX/RGB、类别数、用途、限制、来源及日期。连续色标核查明度与中心；类别过多先用分面/标签/点形/线型。验证实际细线、小点、填充和透明叠加，不只看色卡。
- 实际出图时检查色觉差异、灰度、背景和相邻标记辨识度；无法区别就调整编码并重渲染。仅看参考图不能宣布通过这些检查。
- 图题、图注、Results 都由新任务数据产生。图注覆盖面板、条件、n、独立性、区间、统计和缩写；未知填 `[待补充]`。结果描述区分观察、解释与机制，不把相关、模拟或优化输出写成实验因果。详见 [caption-and-results.md](caption-and-results.md)。

写入后做一个满足输入条件、一个缺关键输入的简短应用推演：前者说明选择与配置，后者说明哪些面板/统计不能推断及可用的较简单表达。只验证决策流程，不声称已运行新图。读图、规则落位、结构/链接检查和范围内事项记录完成后结束本批；没有新规则也可完成一份有根据的“不迁移”记录。后续“继续”优先处理已列出的未完成项，再选择下一批新问题。

## 4. Meaningful deeper study

遇到难读信息先局部放大；含义不明再看图注、变量定义、表格与方法。针对颜色、投影、模型诊断或统计语义提出一个可验证问题再查证，不漫无目标扩展参考库。对科学主张的复算必须有数据、方法和相应授权；缺失时保留具体问题与影响，不“补齐”结果。

可把公共元数据整理、去重和初筛交给可用助手，主代理审阅来源、解释、迁移规则与最终修改；助手输出不是证据替代。未经授权不登录购买、不安装依赖、不上传私人论文，也不把“继续/深入”解释为无限调用或耗尽额度。

## 5. Separate acceptance levels

| 层级 | 要检查什么 | 可以声称什么 |
|---|---|---|
| 参考观察 | 图与图注实际可见；逐图卡覆盖上述维度；未知与矛盾具体记录 | 已完成本批设计细读；不代表验证论文结论 |
| skill 文档 | 触发描述、相对链接、格式、规则冲突、备份、来源与变更范围 | 文档结构/链接检查通过；不代表绘图代码已运行 |
| 假设性应用 | 给新任务说明选图理由、配置位置、缺失数据与验收步骤 | 桌面推演/流程检查；不能称作已生成或测试实际图 |
| 新图运行与科学 QA | 真实 RStudio/Origin 执行、数据映射、统计/单位/区间/掩码/分母检查 | 只声明确实执行的检查和范围 |
| 新图视觉与文件 QA | 逐面板、整图、最终物理尺寸、密集区；色觉/灰度、重叠/裁切、字体、PDF/SVG/所需位图解码和尺寸 | 有依据的通过/待修复/未执行；修复后复验 |

每项用“通过 / 发现问题 / 未执行 / 不适用（原因）”，不能以链接数量、像素数或运行成功标记替代科学与视觉验收。发现无法解决的源图问题可完成学习记录，但不得称源图“全部通过”。

## 6. Handoff and reusable checklist

交付已更新 skill/参考文件、逐图档案、来源与日期、验证记录、备份和简短应用例；不把未生成的图列成输出。实际出图另交 R 代码、配置、来源数据、依赖版本/随机种子、预览、PDF/SVG/所需位图、图题/图注/Results 及命名一致的 manifest，按目标当前要求决定 DPI。

完成前确认：

- 每张范围内的图都有证据卡；放大检查解决了可解决的细节，其余未知已明确。
- 正向设计机制、局限、迁移条件和 R 实现位置齐全；未机械复制配色/构图。
- n、单位、区间、来源、尺度、缺失、变换和限制没有被美化隐藏。
- 通用规则在主文件，图型规则在短参考，来源观察在批次档案；没有重复、过时或冲突条目。
- 每项验收状态有实际证据；未运行模型/新图、未模拟色觉、未验证期刊要求时明确说明。
- 只报告有意义的增量；旧学习未按此新流程重审的，不追认成已细审。
