# 加权状态随时间怎样变化

均值可能落在两个分支之间，给人状态集中在中间的印象。如果每个时点保留了状态样本和相应权重，可以画一列分箱概率，再用同批粒子计算超过指定阈值的概率。如果仅有均值、边际区间或协方差，选用相应的轨迹或区间图。 [状态估计与观测缺失](state-estimation-figures.md)

## 从冻结结果生成可编辑图

在脚手架项目的 RStudio 控制台运行下例。替换列名和单位，显式提供采样计划、状态分箱边界与有科学含义的阈值。权重可以是相对权重，等权抽样可赋值为 1。每行代表一个时点的一次状态抽样。多个对象、运行或模型先按研究问题分开处理。

```r
source("R/plot_state_mass.R")
# 模拟演示。第二个计划时点缺少状态样本。
particles <- data.frame(time = c(1, 1, 3, 3), particle = c(1, 2, 1, 2),
                        state = c(-1, 1, -1, 0), weight = c(2, 1, 1, 1))
field <- state_mass_table(particles, times = 1:3, breaks = c(-2, 0, 2), threshold = 0)
p <- plot_state_mass(field) + ggplot2::labs(x = "Time step", y = "Simulated state")
print(p)
field$summary
```

示例各时点的严格正分支概率依次为 1/3、缺失、0。图中叉号灰列表示该时点没有状态样本。若仅缺观测，而滤波器已给出该时点的传播分布，则保留粒子并另外标注观测中断期。声明输出是基于当时及以前信息的滤波分布，还是使用了后续信息的平滑分布。

## 将每个图元与数值对账

- **每格的分母**是该时点全部有效粒子的权重和。固定状态边界，保留每个分箱，包括概率为零的分箱。区间左闭右开，最后一箱也包含最右端点。遇到非有限状态、负权重或时点权重全零时先追查来源。有 `particle` 列时，工具会核对同一时点内的粒子键。
- **显示范围之外的质量**分别在 `summary$below_range` 和 `above_range`。对有样本的时点，这两项加上 `cells$mass` 的分箱总和应等于 1。缩小可见状态范围时，阈值概率 `above` 继续取全部样本的加权比例，比较符号为严格大于。即使阈值落在箱内也直接从粒子求值。
- **颜色表示单箱概率**。相邻箱宽不等时仍用真实边界绘制，单箱概率与单位状态宽度的密度各有含义。默认色阶为 0 至 1，在多图中可明确指定同一 `mass_max` 加强低质量格的区分度，上限应覆盖全部所比较数据的单箱概率。按整套图已定色卡生成同色相明度梯度。
- **时间坐标保留数值间距**。时间格一律采用计划中的最小正时间间隔作为宽度，较远时点之间保留空白。单时点示例宽度为一个时间轴单位。转为天、小时等数值时保留原时间单位。若画阈值概率曲线，在缺少状态分布处断开。
- **辅助证据按问题选取**。报告 `summary$n` 时明确它是时点内的样本数。有效样本量 `ess` 由归一化权重平方和的倒数计算，用于描述权重集中程度。要解释预测误差，另需有来源的参考状态。选取切片时沿用主图的冻结样本、分箱和共同色阶。
