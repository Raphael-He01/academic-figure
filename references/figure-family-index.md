# 科研图型选用索引

本索引按 scholarly-visualization-lab 的 V01–V32 编号对应研究问题，供 Academic Figure 的第四步查阅。先确认观测单位与研究问题，再决定主图。候选画法需要下表列出的证据。已提供的 R 组件与只提供设计方法的路线见表后说明。

| 编号 | 研究问题与检索词 | 首选画法 | 使用条件及证据不足时的取舍 |
|---|---|---|---|
| V01 | 预测偏差集中在哪些样本？预测、残差、PLS、PLSR | 留出观测对预测的等比例散点，按需对齐边际分布 | 核对样本键、划分、单位与残差方向。训练集只能展示拟合。 |
| V02 | 预测范围覆盖了多少未来观测？扇形、校准、PIT、GPR、ARX | 对齐时间的分位带及覆盖率图 | 核对预测时点、留出真值和区间定义。PIT 需要每条观测的预测分布及离散值处理约定。 |
| V03 | 哪些后验参数共同变化？角图、联合抽样、HDR、BLR、MCMC | 参数对散点和对应边际 | 按同一 draw 和链号对齐。只有分位表时画各参数区间。 |
| V04 | 平均值是否掩盖了状态分叉？粒子、概率质量、状态场、PF、HMM、GMM | 时间 × 状态分箱的加权概率图，必要时补阈值分支概率 | 保留时间网格、权重、分箱和越界质量。区分缺测与该格概率为零。 [R 模板与用法](weighted-state-fields.md) |
| V05 | 组间差别来自整体平移还是少数样本？雨云、小提琴、raincloud | 原始点和分位概括，连续观测充足时再加密度 | 交代独立样本数、配对及密度带宽。少量离散取值直接画点。 |
| V06 | 哪些真实个体代表各组？PAM、medoid、样本图谱、聚类、annotated atlas | 全样本特征矩阵，标出分组和代表样本 | 元数据按 ID 连接。以原 ID 标明观察到的代表对象，另行说明特征变换。 [R 模板与用法](sample-atlas.md) |
| V07 | 哪些变量一起变化，哪些与模型输出有关？相关矩阵、变量重要性、correlation | 相关矩阵及按相同变量顺序对齐的模型结果 | 有效样本数随变量对而变时须交代。侧条和连线分别需要实际重要性估计及关系证据。 |
| V08 | 同一批对象怎样改变去向？阶段、流向、Sankey、alluvial | 相邻阶段的带宽表示可追溯转移量 | 独立的各期总数只支持比较构成。连续多阶段路径需要贯穿各段的键或联合计数。 |
| V09 | 哪一项抵消或增加了总量？瀑布、分解、贡献、LCA、MARS | 从基准到终值的带符号贡献 | 在分析尺度逐项对账。重要性分数只支持排序。 |
| V10 | 关系有多强、流向哪里？有向边、弦图、PROMETHEE、PageRank | 已知边集用有向图或按源、目标排列的矩阵 | 说明边的单位、方向与筛选。密集双向边用非对称矩阵精读。普通线段只表达连接。 |
| V11 | 同属一个模块的关系稳定吗？共分配、瓶颈、MaxFlow、Louvain、min-cut | 重复划分给共分配矩阵，容量问题给饱和边及割集 | 共分配的分母是两个节点共同参加的运行次数。瓶颈判定需容量及求解结果，单凭节点度数可描述连接数。 |
| V12 | 相同份额是否对应不同规模？三元、配方、mixture | 三成分图，另列总量 | 三项同分母、非负且闭合，顶点顺序固定。只有两个独立量可用普通散点。 |
| V13 | 合计和组成怎样变化？堆叠、径向、composition | 同基线的总量和构成，类别用固定顺序 | 核对组成可加，若做径向条须说明半径或面积的编码。比较细微差异时改用共有基线的点。 |
| V14 | 方案在哪些指标上互有取舍？Pareto、平行坐标、VIKOR、NSGA | 可行解散点或同尺度的指标轮廓 | 保存各目标方向、标准化和完整目标集。二维投影不能单独判定多维非支配。 |
| V15 | 迭代为何趋稳或振荡？蛛网、cobweb、递推、Bass | 递推函数和等值线之间的逐步路径 | 需要确定的一维映射、初值与实际迭代顺序。仅有时间观测时保留时序图。 |
| V16 | 哪一段频率或波长发生变化？光谱、时频、相位、wavelet | 共享横轴的谱线或时间频率场，标记原窗口 | 区分波长和频率，写明单位、窗口及变换。相位采用循环标尺，低支持处遮罩。 |
| V17 | 两个输入共同改变响应吗？响应面、等值线、RSM、GAM | 在实际求值域画等高线，沿指定切片精读 | 区分计算网格和采样点。二维支持不足时显示原点或在有支持范围内给条件曲线。 |
| V18 | 边界附近哪些样本难以判别？隶属、异常分数、概率、SVM、DBSCAN、FCM | 原始点叠加已定义的分数场或观察到的误分类 | 后验概率、隶属度和异常分值用各自的图例。高维模型只在投影或已说明的切片上解释。 |
| V19 | 什么时间发生改变？变点、事件栅格、PELT、Hawkes | 时序与候选变点对齐，多次求解时比较位置稳定性 | 单有事件时间可画栅格。声称变点对惩罚值稳定时需有参数扫描结果。 |
| V20 | 多大损失会被超过？尾部、生存、超越、重现水平、Cox、EVT、copula | 经验超越阶梯，删失随访用相应生存估计 | 对数轴另记零频和分母。外推重现水平需尾部模型、暴露周期及区间，不能从末阶直接延伸。 |
| V21 | 输入的直接及交互作用有多大？Sobol、Morris、龙卷风、tornado | 分开一阶和总效应，或按扰动幅度比较局部效应 | 核对输入依赖、统计量单位及采样误差。总效应之和可以超过 1。 |
| V22 | 哪组扰动会改变方法优劣？双参数、压力测试、bias grid | 共同网格上的性能差，叠加零边界和同网格剖面 | 使用同一评估对象及扰动，记录冻结或重拟合。缺少对应剖面时只展示已求值点。 |
| V23 | 名次或聚类对扰动稳定吗？排名概率、ARI、代表漂移、TOPSIS | 排名给全名次概率，聚类用重复结果和代表位移 | 同对象键上比较划分，处理标签置换。比较 medoid 漂移先匹配组，记录匹配尺度与未匹配组。 |
| V24 | 鲁棒保护值得花多少钱？情景集、缺供、超额成本、robust optimization | 成本与缺供的权衡，并列设计集外的超越曲线 | 配对压力抽样并保留失败求解。可行性声明限于已定义的保护集。 |
| V25 | 地理分布与纬度梯度是否一致？全球点位、地理覆盖、latitude | 点位图，必要时配纬度剖面 | 需要坐标元数据和测量口径。纬度带采样量不均时给每带样本数。 |
| V26 | 局部枢纽是否代表真实流量？OD、流网、空间网络、spatial flow | 低对比底图上的流量及同源放大 | 连接需 OD 数据。仅有坐标可另作明确标识的邻近示意。筛边报告边数及总流量的保留比例。 |
| V27 | 城市差异发生在哪个原生像元？栅格、城市热场、raster | 原格网及坐标对应的局部或剖面 | 保留掩膜、时点和分辨率。图例区分缺测陆地、水体和有效零值。 |
| V28 | 地表和地下结构能否配准？地层、剖面、三维、geoscience | 共享相机、坐标和范围的分层视图 | 写明垂直夸张。缺少基准时只能标作示意，不能用精细海岸或地形补出精度。 |
| V29 | 机制如何跨隔室传递？能量平衡、箭头、剖面、mechanism | 局部剖面追踪有定义的物质或能量路径 | 给每条关键箭头标来源、去向、方向依据。宽度代表实际通量时补单位和数值。 |
| V30 | 求解器的好结果能重现吗？多种子、计算预算、遗憾、PSO、ACO | 按相同预算比较轨迹、可行率及多次运行分布 | 说明终止与失败规则。单条最优轨迹不支持算法可靠性结论。 |
| V31 | 多个维度的轮廓如何改变？雷达、多指标、radar | 固定轴序、刻度和方向的轮廓，精确比较时用对齐点图 | 给出归一化基准，避免把因轴序而变的多边形面积当总分。 |
| V32 | 流量能解释库存变化吗？存量、供需、终端约束、MILP、MPC | 对齐净流、库存轨迹和上下界 | 区分功率与能量，按时长及效率换算后核对相邻存量和期末约束。只有存量时只能画其轨迹。 |

## 从索引到成图

用 `python3 scripts/figure_routes.py 变点` 或 `python3 scripts/figure_routes.py V06` 查条目。也可在已有事实表时运行 `python3 scripts/figure_routes.py V08 --facts facts.json`，直接查看首选画法需要补齐哪些条件。检索工具按命中返回；程序化判断请使用 `chart_guard.py` 的退出状态。可用研究问题或模型别名检索。同一模型有时会命中多个条目，按当前要解释的输出选用。选图时把实际输入与第四列核对，将缺少的依据及可用替代写进图稿契约。两张图都回答同一个问题时，共用坐标和编码有利于比较。若一张讲整体、另一张讲失败个案，则让第二张展示可定位的记录及选择标准。

V04 和 V06 附有本轮新增的 R 组件。V12 可调用脚手架的三元点组件，V16 有谱线组件，V01 等另有冻结的模拟示例。其他条目按项目数据和方法选择或编写绘图代码。检索命中只定位指南。 [模型选图与证据核对](model-output-routing.md) · [科研图稿检查](rendered-qa.md)

## 调用原示例库

已装 scholarly-visualization-lab 时，在它的目录运行 `python3 scripts/catalog.py --query 后验 --limit 2` 等检索。查看命中项目的预览、方法说明和执行状态，再决定可借鉴哪一处构图。重绘优先选带冻结数据及运行说明的套件。核对模型历史时区分已完成、已撤回和只讨论过的项目。

对历史图的反馈要跟随图的版本。例如，若图中的均值掩盖了双峰，修改主编码并在同一数据上对照分支质量。若问题是标签过密，则调整字号、位置或排版并复核实际宽度。项目记录可写下原问题、改动、数据版本、前后导出及用户意见。只有明确认可过的组合进入默认偏好，色值在归档中出现频繁仅说明使用次数。整套图的色卡在第六步确认一次。 [配色选择](palette-system.md)
