## Candidate Codex skills and libraries

The curated installer catalog contained no academic/scientific plotting skill at the access date. Public candidates were distinguished from R packages, Origin templates/apps and tutorials rather than treated as interchangeable.

- `dazhiyang/scientific-plotting-skill` (MIT): a real installable skill, but incomplete for this requirement—no Origin handoff, scripts, legend/Results workflow or end-to-end validation.
- `adjurtime/scientific-figure-skills/origin-figure` (MIT): the strongest Origin-oriented candidate, but requires Windows, licensed Origin and an Origin MCP environment unavailable here.
- `O0000-code/SSCI-Plots` (MIT) and `Yilin399/science-plotting` (MIT): useful Python references, not an R-first Origin workflow.
- `AgentFigureGallery` (MIT, alpha): broad but large and installation-heavy relative to the requested minimal workflow.
- Candidates without an explicit license, with proprietary terms, or with unsafe cleanup/install behavior were not installed.

The personal `academic-figure` skill was therefore created instead of presenting a mismatched third-party repository as complete.
