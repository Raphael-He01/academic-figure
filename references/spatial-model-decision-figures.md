# Spatial prediction and multi-objective decisions

Use for spatial prediction validation, matched landscape portfolios, multi-objective search and predicted-versus-reference outcomes. Read [spatial geometry rules](spatial-figures.md) for CRS/raster handling and [forecast/decision rules](forecast-decision-figures.md) for general decision comparisons. Observations: [three user references](reference-observations-2026-10-18-ecology.md), reviewed 2026-10-18. These are figure-design and analysis-contract rules, not implemented models or verified reference results.

## Select the evidence needed

Distinguish four questions: where the prediction varies; whether it predicts held-out outcomes; which choices a specified preference favours; and how stable those choices are to search/prediction uncertainty. Use only panels needed for the question. A map alone does not validate predictions; a good prediction score does not establish decision utility.

Before drawing, record the available spatial units/CRS, response and reference source, split/fold IDs, model predictions, eligible planning cells and areas, objective definitions/directions, feasibility constraints and selection rule. Keep fitted models, evaluation summaries and plotting configuration separate. Missing model outputs or a missing truth source require a narrower figure, not fabricated values.

## Prediction and held-out validation

- Use matching extent, CRS, resolution and aspect for paired maps, and declare each valid-data mask. A full-area prediction can accompany a residual map restricted to available reference locations: show this coverage difference instead of filling missing residuals. Quantitative method comparisons need a common valid evaluation basis. Distinguish predicted probability (sequential, normally 0–1), signed residual (diverging around a defined zero) and uncertainty (its own defined statistic). Give each mapping its own key and state subtraction direction/reference provenance.
- Identify spatial blocks, split rule and exclusion-buffer distance/geometry; map both blocks and buffer if needed to substantiate the design. Keep excluded cells distinct from zero-valued predictions. Report test observations, spatial block count and sampling hierarchy separately; blocks are not automatically independent replicates, so justify the dependence assumptions used for uncertainty. Any preprocessing, tuning and feature selection must respect the split; an attractive held-out-block map is not a leakage audit.
- ROC requires the event class, common held-out cases, threshold convention and an explicitly named AUROC. Add uncertainty only from a justified design; resampling should reflect spatial dependence. When class imbalance makes ROC incomplete, consider precision–recall with prevalence/baseline disclosed. Do not evaluate methods on different masks without naming that change.
- **Binary probability calibration is not quantile calibration:** plot mean predicted probability against observed event fraction for stated bins, with an identity line. Record bin edges/rule, counts, weights, empty-bin handling and any interval construction. Sparse bins should be visible as a limitation. A Brier score assesses probabilistic accuracy, not calibration alone. Calculate all comparison summaries on the declared test set.
- For permutation importance, name the held-out metric, sign, permutation unit/repeats and whether intervals describe repeat variability or inferential uncertainty. Respect spatial/group structure where appropriate; correlated features can share or distort importance. Preserve negative estimates instead of cropping them away. Importance is not causation.
- Label faint response curves as ICE only if that is what was calculated. Name the averaging/conditioning used for a partial-dependence curve and distinguish it from ALE or another method. Show data support or qualify extrapolation; correlated predictors can make varied combinations unrealistic. Neither a curve nor its visual smoothness establishes a causal effect.

## Matched spatial portfolios

- Fix background field, coordinate geometry, eligible units and scale across panels. Compare plans on the same objective definitions and constraints; equal selected area does not imply equal cost. For unequal cell areas, check summed area rather than cell count. Define eligibility and any fractional/overlapping selection.
- Separate the background probability from selection identity. If background values need numerical reading, provide a shared colourbar; otherwise label the background as contextual. Semitransparent selection changes visible colours, so do not decode probability from overpainted cells; outlines, hatching or a companion unmasked map can help.
- Keep summary metrics in a fixed order. Name each percentage denominator and cost unit/index. Do not add percentages from different totals or describe a summed-probability proxy as species richness or measured ecological gain.
- Define preference weights, normalization, objective direction and representative-plan selection. A balanced plan is conditional on that rule, not a universally best solution. State whether connectivity or other spatial constraints are included; fragmented selections are not automatically an algorithm failure if connectivity was never an objective/constraint.

## Multi-objective evidence and search diagnostics

- Declare all objective directions, feasible set and domination convention/tolerance. Evaluate dominance in the full objective space; a two-axis projection can hide improvement in the third objective. Say sampled nondominated set, not a proven global Pareto frontier, unless there is actual proof.
- Encode a third continuous objective with a named ordered scale and highlight selected plans with a separate category/shape key. If selected-point fill overrides the continuous mapping, state that exception or use an outline. A gray feasible-plan cloud needs a sampling description; it is not automatically a statistical null distribution.
- Parallel-coordinate axes are discrete objectives, not a time trajectory. Record fixed normalization bounds and transform costs so improvement directions agree, while retaining access to raw units. Do not normalize each plan independently. A profile shows trade-offs; ranking requires a stated utility/weight/distance rule. Explain values outside fixed bounds rather than clipping silently.
- For hypervolume, record objective directions, transformation/normalization, common bounds, reference point, feasibility filtering, and whether the set is the current population or a cumulative archive. Use the same definition across runs. Values above 1 can be valid depending on the reference box; do not force a 0–1 interpretation. A cumulative archive may be monotone under fixed definitions, while a current population need not be.
- Show seed/run variability without treating a few similar curves as proof of global convergence. Keep budgets/termination conditions comparable and disclose selection of a displayed run. Never smooth away reversals to make search look more stable.
- Filled/open endpoints joined for prediction and reference are paired values, not an uncertainty interval. Define reference provenance (simulation truth versus field measurement), matching units and aggregation. For reference reassessment of a selected plan, keep the plan fixed; reoptimizing under truth answers a different question. Handle overlapping endpoints with visible outlines/annotations, or disclosed offsets only along the categorical direction; never shift their quantitative coordinates.

## Style, writing and verification

Use separate named mapping namespaces for model, portfolio, run/seed and continuous field. Reuse portfolio identity across maps, objective profiles and paired outcomes, but do not infer that a similarly coloured model or random seed is that portfolio. Give symbol semantics their own keys. Configure maps, colourbars, plot widths and summary-row spacing at final physical size; a six-panel report may need to become two journal figures.

In the caption record simulated/observed status, evaluation units and split, interval/bin definitions, objective denominators, constraints, normalization/reference point and what was held fixed. Describe observed performance, model interpretation and conditional decision preference separately. Avoid converting a predicted ecological proxy into a demonstrated conservation benefit.

Before delivery, check matched masks and keyed plan IDs; objective direction/denominators; block and buffer visibility; sparse calibration bins; interval and endpoint definitions; alpha compositing; continuous-scale lightness; grayscale redundancy; dense points and small legends at final size. Preserve editable axes/text and effective raster resolution. Report unrun scientific/visual/export checks as unrun.
