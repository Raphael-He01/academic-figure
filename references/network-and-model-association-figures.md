# Geographic networks and model-association composites

Read for maps combining spatial nodes/edges and coordinate-linked insets, or for figures joining a predictor matrix, importance strip and model effects. These are plotting rules, not network-construction, statistical-fitting or causal-identification code. See [the image-specific observations](reference-observations-2026-10-27-network-thermal-matrix.md).

## Geographic network: preserve structure and geography

- Before drawing, validate node IDs, coordinates and CRS; edge endpoints must refer to known IDs. Record whether edges are observed flows, relationships, routes, or derived proximity, together with direction, distance method, k/radius, symmetrization, tie handling, duplicate/self-edge rules and temporal scope. A nearest-neighbour union is not traffic; infer no direction for an undirected graph.
- Keep geographic geometry and network layout distinct. Use the declared projection for nodes, edge paths, boundaries, insets and clipping. For geodesic nearest neighbours, calculate distance on the appropriate ellipsoid; straight display chords are not automatically routes or shortest paths. Declare how dateline-crossing edges are drawn.
- Layer context below edges below nodes; choose line contrast and opacity so endpoints remain visible. Explain edge width, colour or alpha if they carry values; overlapping translucent edges accumulate visually and do not by themselves quantify flow. If the graph is too dense, label any aggregation/filtering threshold and preserve the full edge table; consider an inset or a separate view before removing data.
- Bind node colours to their variable and units. If node area encodes degree or magnitude, provide a quantitative size key or direct values, encode area rather than radius and disclose scale limits; if visual size is fixed, say so. Colour and size mappings need separate legends unless a single explicit encoding explains both.
- Derive the main-map selection box and inset crop from one stored extent/CRS, with the same node IDs, edge policy, colour limits, symbol meaning and explicit inclusion rules. Compare plotted IDs and segment endpoints inside the crop; distinguish edges crossing the boundary from fully contained edges. A connector is a layout aid, not a relationship in the data.
- For observed origin–destination flows, define node/area keys, time window, units, direction, within-area/self-flow treatment, source and denominator for each displayed share. If using a logarithmic colour or width mapping, define zero, missing, thresholds and any flow excluded from display. Overlapping line opacity does not provide a reliable visual sum. Keep the quantitative flow key separate from a categorical regional key; inset rules must specify whether flows crossing its boundary remain visible.
- Where levels are calculated separately within regions, preserve a stable label/colour mapping but disclose each region's underlying classification, comparator and thresholds. The same level across regions need not represent the same absolute flow or threshold; provide absolute values or a common-scale companion when cross-region magnitude is the question. If a linked fraction curve shows only a subset of levels, name the subset instead of implying it covers the full map legend.
- For an accompanying distribution or concentration curve, name both axes' numerator and denominator, population, weighting, ordering, missing/zero handling and the equation; separately define any dashed benchmark or auxiliary curve. Endpoint labels alone do not identify the statistic. Treat county or other aggregated-unit counts as geographic units, not automatically independent individuals. See [the 2026-10-28 reference review](reference-observations-2026-10-28-raster-inset-commuting.md).

### Fine visual treatment for dense flow maps

- Compose in layers: a near-neutral land/water field and thin reference boundaries, then the complete declared edge set, then any supported nodes or named highlights, followed by labels, scale and inset. Assign each layer an evidence role; render geography quietly enough to support orientation without making light data strokes disappear. No node symbols are required if the actual node data and question do not support them.
- For positive continuous flow/share, consider an ordered light-to-dark sequential scale with a single hue-family transition; choose actual colours and data limits from project configuration. If the span covers orders of magnitude and a log transform is justified, retain ticks labelled in original units and explicitly handle zeros, negatives, missing values and limits. Dark/light does not imply increase unless the legend makes the direction clear. Give each other variable, including regional rank, its own discrete or sequential mapping and legend.
- Establish relative emphasis at the **final placed size**: context < ordinary edges < focal evidence and readable text. Tune colour, line width and alpha together on the actual background; check thin isolated lines as well as dense intersections. If an important weak edge becomes invisible, use a separate view or an explicitly marked selection, rather than hiding it or increasing all lines until hubs become opaque.
- Alpha compositing creates density-related darkening, not a quantitative flow total. For equal-colour, equal-opacity strokes over a background, the combined opacity of n overlaps is `1 - (1 - alpha)^n`; mixed colours, antialiasing, drawing order and export devices complicate the observed result. Do not infer an individual edge's value from an intersection. Add a keyed table or a separate quantitative aggregate when precise comparison is needed.
- Reserve genuinely unused map space for the horizontal colourbar and its title/ticks, and a separately bounded inset with a short location label. Test the legend and inset against the plotted geometry; move them outside the map when they hide relevant links or data. Make a selection outline and any connector visible but quieter than the information marks, and validate their shared geographic extent. Do not recreate another figure's distinctive composition as a default.
- Keep ordinary labels neutral and readable; select map aspect, panel proportions, padding, line treatment, legend extent, inset size and typography from project-specific settings. Inspect an overview and enlarged dense/isolated regions in the PDF/SVG and at actual print size; review deutan/protan/tritan and grayscale views using the real composited marks. Rasterize dense edges only if needed and allowed, retain vector text/boundaries, and verify effective placed resolution and editable source data.

## Aligned matrix, importance and association effects

- Store a unique predictor key and one explicit ordering across matrix columns/rows, importance, labels and effect endpoints; validate missing, duplicate and unmatched IDs. Preserve the full table when a figure shows only a subset. If ordering uses test-set importance, disclose that choice and avoid treating the selected order as independent evidence.
- Record the sample, pairing/missing-data policy and method for each correlation; use a symmetric −1 to 1 scale centred on zero when showing Pearson r and provide a missing-state symbol distinct from zero. If displaying one triangle, state which half and whether self-correlations/diagonal are omitted. Define whether square area, fill or both encode magnitude; avoid redundant encodings without a clear key.
- Label importance by the actual metric, baseline, test set, permutation or calculation unit, and repeat variability when available. A negative importance can be meaningful and must not be silently clipped to zero. Group-held-out evaluation requires group IDs and a recorded split; observation count and group count are not interchangeable.
- For model links, define the fitted response, coefficient scale/standardization, model, group structure, comparison and confidence or other interval when supplied. Independently label sign, width/area mapping and line type. A corrected q requires a defined test family, method and threshold; mark absent statistics missing rather than adding solid/dashed significance. A link is an association unless the study supports causation.
- A dense star/arc display is not always the most precise comparison: if line overlap or width obscures magnitude or intervals, use an aligned dot-and-interval view and separate correlation panel. Never infer a confidence interval from a connected line; do not fabricate unavailable uncertainty.

## Configuration and final-size checks

In the project's existing R configuration specify region/inset extents and CRS, palette/limits/NA colour, stable variable order, point-area and edge scales, legend sizes, labels, curve spacing, canvas and font hierarchy; these are project-specific fields, not claimed capabilities of the unchanged scaffold. Keep graph building, statistical calculations and styling in separate scripts. Create and export saved R code from RStudio; use project-specific packages only if justified and actually available.

Reconcile inset IDs and masks; inspect overlapping edges, line endpoints and arrowheads, area-key values, colourbar zero and saturation, labels and footnotes at final size. Check colour-vision and grayscale views with actual marks; use redundant line types/shapes when needed. Inspect every panel and complete composition for clipping and hidden marks. Report measurements and unsupported layouts honestly under [rendered QA](rendered-qa.md).

Captions should identify the graph definition, data source, geographic and observational units, sample/group counts, correlation method and sample policy, model effect and uncertainty, test family/correction and exclusions, as applicable. Record unavailable information as missing. Do not present a model-generated proximity graph as empirical interaction or a correlation matrix as a causal network.

## Paired observed and modelled links

For paired observed/fitted OD links, require matched endpoint keys, direction, temporal/geographic scope and explicit coverage mask before comparing; preserve a common magnitude scale. A signed difference or declared pseudocount log-ratio needs a separate zero-centred key, named numerator/denominator, pseudocount units and clipping limits. Report whether fitting used only observed positive links; missing/unreported links are not zeros. A calibrated map is not held-out predictive validation. Inspect dense composited strokes and offer a keyed table or explicitly marked subset/aggregate if individual links cannot be read. Configure mappings and extents in the project, then reconcile edge IDs and inspect the final render; the scaffold does not implement this view.
