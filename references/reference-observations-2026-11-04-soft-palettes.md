## Shared evidence card: applies to every sheet below

1. **Purpose/chart choice (visible):** each sheet showcases colours through nine chart panels. Distribution, response, correlation and surface examples illustrate marks; they do not justify choosing those chart types for arbitrary data. See individual panel inventory below.
2. **Layout (visible):** large title, horizontal palette strip, three-by-three panels, repeated letter tabs and pale heading bands. The bands reuse the theme and separate panels. **Transfer:** a consistent local key and spacing; omit oversized promotional titles, watermarks and decorative header bars in a manuscript.
3. **Type/marks (visible):** dark title/axis text, softer fills, stronger outlines and points, thin grids, local legends. Some sheets colour axis text blue; neutral dark text is the preferred transfer. Original font, pt, alpha, physical dimensions and stroke widths are unknown.
4. **Colour (visible):** near-white backgrounds, greyed hues and same-family tints create quiet depth. Category colours and continuous surface/heatmap gradients are different design problems; a visually harmonious set does not establish perceptual order.
5. **Keys/annotations (visible):** swatches explicitly print HEX labels; some also print RGB. These labelled HEX values can be transcribed without estimating pixel colours. Chart keys, intervals, ellipse regions, p values and error bars are illustrative; their analysis and definitions are unavailable.
6. **Integrity (unknown):** no underlying observations, uncertainty methods, sample sizes or export settings were provided. Do not reuse numerical annotations, invent significance, copy peak assignments, or infer that all curves share comparable units. A colour template is not a scientific method reference.
7. **Files/scale (measured):** each supplied PNG is 1086 × 1448 pixels. Original vectors, embedded fonts, final print size and effective DPI are unknown. Watermarks and small text limit detailed inspection; no colour-vision or final-size figure acceptance is claimed.
8. **Decision:** adopt restrained hue families, warm fills and a few darker anchors; adapt small-mark contrast and statistical colour semantics; reject compulsory nine-panel layouts, decorative 3D/polar views, automatic gradients and palette-only claims of accessibility.

## Reusable profile and what it does not establish

The user's requested default is **simple, fresh, predominantly light and warm**. The full set contains cool and dark families as well: sheet 5 supplies the preferred starting direction; sheets 1/3 can add dusty rose or lavender; sheets 6/9/10/11 are optional anchors or alternatives. Do not cycle themes between panels depicting the same groups.

For new project configuration, a starting three-category set is apricot `#E7AF98`, jade `#82B6AB`, grey-blue `#ACBFD0`; cream `#F3E6CE` is a supporting area, not a fourth default small-mark category. This is a selected combination, not an automatic change to the bundled R example. Bind entries by real group names. When lines or small points are too pale, use darker same-family marks with lighter fills, then inspect again; do not indiscriminately darken the whole page.
