# 从模型输出选图

先写下读者要做的比较，再指出哪几行数据可以放在一起比较。拟合名称相同的两张表，一张可能只给参数分位数，另一张可能保留每次抽样的完整参数。前者支持画区间，只有后者能回答两个参数怎样一起变化。把选中的图、依据和仍缺的字段写进现有五点契约。 [图稿契约](figure-contract.md)

图型不确定时，可查 V01–V32 的使用条件，例如运行 `python3 scripts/figure_routes.py V19` 查找变化点的定位与稳定性证据。命令从 skill 根目录运行。 [32 类图型索引](figure-family-index.md) · [检索脚本](../scripts/figure_routes.py)

## 三种容易画错的关系

| 读者的问题 | 哪些证据支持这种画法 | 证据有限时怎么画 |
|---|---|---|
| 两个参数是否相互补偿？ | **后验角图**。每行来自同一次联合后验抽样，有至少两个参数、可核实的抽样键和权重约定。对角线给边际，非对角线给同次抽样的参数对，同一参数各处共用刻度。 | 只有各参数的均值或分位数时，分别画点和有定义的区间。 |
| 对象在哪一步改变了状态？ | **阶段流向图**。逐对象记录能跨阶段按 ID 对齐，或有来源明确的相邻阶段转移量。带宽对应已核对的人数、质量或流量，节点标出单位。 | 只有每阶段各类别的总数时，画并列点图或堆叠柱。两个阶段即使各有 10 个 A 和 10 个 B，也可能全员留在原组，或全员对调。 |
| 从基准到终值，哪些项增加或抵消了变化？ | **贡献瀑布图**。定义基准、加法尺度和同单位的带符号分项，逐对象核对 `基准 + Σ分项 = 报告终值`。按业务或模型顺序排列，保留负项和零项。 | 有重要性分数时画排序点图。有可核对的两端、缺少分项时画端点差。只有一项发生变化时，直接标注该差值往往更清楚。 |

- **联合抽样。** 多链抽样中的编号可能在每条链上重新开始，按链号和抽样号一起对齐。等权抽样记明等权，加权抽样在统计中保留权重。为显示而抽稀只影响散点。若为密度轮廓标注 95% 概率，需要按密度从高到低累积网格概率质量，并检查网格外截掉的质量。
- **阶段流量。** 对每个中间状态核对流入、流出及有记录的进入与退出。汇总的相邻转移支持画该段流带。要让同一条彩带连续跨越三个以上阶段，还需要完整路径或逐路径的联合计数。
- **可加贡献。** 用底层数值求和后再舍入，核对允许误差和单位。模型在对数尺度上可加时，在该尺度核对并标轴。比较不同配置时，先确认总量和分项使用同一个基准与分母。

## 其他模型输出如何取舍

| 已经拿到的输出 | 主图回答什么 | 可加的辅助证据 |
|---|---|---|
| 留出样本的实测值和预测值 | 同单位、等比例的预测对实测散点揭示哪些样本偏离等值线 | 有稳定样本键时给同批残差。有预测分布时才评价分布校准。 |
| 随时间变化的状态样本与权重 | 用时间与状态的概率热图保留多峰和分支 | 按同一分箱和范围取切片。对每个时点核对总质量，区分零概率与缺测。 [状态分箱方法](weighted-state-fields.md) · [模拟双峰图](../examples/model-output/preview/state-mass.svg) |
| 样本特征矩阵及分组 | 热图保留个体差异，行列用同一套样本与特征键排序 | 按原 ID 标出真实代表样本，标明标准化方向。缺测格和有效零值分别编码。 [样本对齐方法](sample-atlas.md) · [模拟站点图谱](../examples/model-output/preview/sample-atlas.svg) |
| 参数扰动、重复求解、配置排名 | 单参数用带基准的效应图，双参数用差值场。排名变化可用名次概率矩阵 | 写明哪些量固定、哪些模型重新拟合。剖面取自同一压力网格。重复情景频数的解释限于该抽样设计。 |
| 三个成分或多个优化目标 | 三个非负成分经核对在同一分母下和为 1 时，可用三元图。多个目标的取舍可用可行解散点图 | 份额相同但总量不同时另示总量。标注非支配解时按全部目标判定，并注明搜索过的候选范围。 |
| 地理点、网络或格网 | 按观测粒度选点位图、流量图或原生格网图 | 用同一坐标范围框出密集区再放大。筛边时同时报告保留边数和流量占比。多层剖面统一相机和坐标单位，标明垂直夸张倍数。 |
| 过程中的实体、隔室与有依据的连接 | 画可编辑的机制图，让读者沿路径追踪输入、传递与输出 | 逐箭头记录起点、终点、物理含义、方向依据和证据。箭头宽度表达通量时须有量值与单位。 |

非对称的转移或偏好矩阵另需标明行列方向。留出集、扰动、空间底图和机制箭头有各自的核对方法。 [预测与决策](forecast-decision-figures.md) · [状态估计](state-estimation-figures.md) · [空间图](spatial-figures.md) · [机制图](vector-schematic-workflow.md)

## 同一套图怎样保持清楚

整套图在第六步选一次色卡，默认推荐**雾海玫瑰**。把类别与颜色绑定，跨图沿用。连续大小用单调明度，有意义的正负偏差用以参考值为中心的发散色阶。缺测和真实零值分别标识。放大窗使用主图的原始记录、相同编码和可追溯的范围。以实际放置宽度检查浅色细线、标签、图例和灰度区分度。 [色卡与调用](palette-library.md) · [导出检查](rendered-qa.md)

收到“几张图太像”的反馈时，比较每张图让读者看到了什么。若两张都只显示平均趋势，而问题是哪些样本失效，就把一张改成同批样本的残差图。换布局或配色时沿用冻结数值、划分和权重。如需重拟合，单独记录分析变化。将反馈和复核结果记在项目内，经用户认可再更新长期偏好。

## 调用与复核

可先运行 `python3 -B examples/stage-flow/compare.py`。这份模拟登记表追踪六件物品经过三次分派。每次都是 A、B 两处各三件，程序按物品编号核对相邻分派，分别数出实际换过位置的件数，再对比只保留各期总数时可以选择的画法。 [示例登记表](../examples/stage-flow/desks.csv) · [核对代码](../examples/stage-flow/compare.py)

两幅模拟图可从同一个 [R 脚本](../examples/model-output/render.R) 重绘。在仓库根目录的 RStudio 中运行 `source("examples/model-output/render.R")`，再运行 `render_model_examples("my-previews")`。使用新目录保存输出。

在 skill 目录中运行以下命令。第一条列出九类画法的证据字段，第二条给出已确认事实支持的候选，第三条指出指定画法还缺哪项证据。 [条件检查脚本](../scripts/chart_guard.py)

```bash
python3 scripts/chart_guard.py --list
python3 scripts/chart_guard.py --suggest facts.json
python3 scripts/chart_guard.py stage_flow facts.json
```

新示例对应的检查名称为 `weighted_state_field` 和 `sample_feature_atlas`。前者核对时点、粒子、权重和状态分箱，后者核对实际样本、注释连接及特征尺度。通过后由各自的 R 组件检查传入的数值和键。

例如，已知两次盘点的顺序、计量单位与各期总额，缺少逐项转移记录时，`facts.json` 可以写成下面这样。

```json
{
  "ordered_stages_confirmed": true,
  "flow_unit_confirmed": true,
  "transition_links_verified": false,
  "stage_totals_reconciled": false
}
```

此时采用两期构成图。只有核对过链接来源和各中间状态的流量平衡，才把对应值改为 `true`。工具只读取这些布尔事实，原表的键、数值、权重和单位由项目代码或分析者核对。候选之间的取舍取决于研究问题。
