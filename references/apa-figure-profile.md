# APA figure profile: explicitly selected

Read only when the user, manuscript template or destination explicitly requests APA figure formatting. It is an additional profile, not a replacement for the generic journal/report profiles, the approved RStudio/Origin production routes or Chinese-default prose.

## Components and numbering

Use the figure number and a short descriptive title as distinct components above the image, with explanatory notes below it. Format the number in bold and the title in italics; apply the specified APA edition's title capitalization rather than automatically reusing a journal's caption syntax. The upstream summaries contain inconsistent placement and casing statements, so do not copy their combined caption block as authority.

Number figures in order of their first substantive text reference. Ensure each is cited and the reference points to the correct artifact. Use appendix-specific numbering when required by the manuscript structure.

A note explains symbols, abbreviations, sample definitions, interval/test information, rights and necessary qualifications. Only include statistical details supported by the analysis. An adapted figure needs the appropriate permission/credit statement, not a fabricated attribution example.

## Typography and encodings

Follow the chosen manuscript template and verified APA edition for figure lettering and surrounding document text. Keep those settings in this profile's project configuration. Do not import the upstream fixed column widths, all-format DPI threshold or an in-image title into every project.

Check labels at their actual placed size and use a legible consistent sans-serif face where appropriate. Caption/document typography and text inside an image are separate settings. Do not make a universal small-text rule from a source's sample theme.

The [existing palette system](palette-system.md) controls data semantics and accessibility. A named palette alone does not establish readable marks. Direct labels can replace a redundant legend when their meaning is complete.

## Delivery boundary

Keep one canonical caption record containing number, title and note; use it consistently in document and figure handoff. The default language remains Chinese unless English submission is requested. APA styling does not authorize rewriting the scientific conclusion.

For inserting finished artwork into a manuscript, use [LaTeX inclusion](latex-inclusion.md). That guide does not select a new APA font size or redraw the figure. Apply [rendered QA](rendered-qa.md), with thresholds set from the active profile, and review the compiled manuscript placement.

Record which APA edition/template governed the result and which details still require verification. This reference is a scoped formatting workflow, not a claim that every upstream APA statement has been officially verified.
