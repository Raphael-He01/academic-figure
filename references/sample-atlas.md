# 按样本编号对齐的特征图谱

当问题是“同一组内部有哪些不同的特征轮廓”，一列对应一个实际样本、一行对应一个特征的矩阵可以保留组内差异。顶部色条给出已确定的类别，倒三角定位拟合结果中有编号的代表样本。只有组均值时，可画组轮廓或点区间图。组均值已经丢失列与列之间的个体差异。

## 准备两张表

测量宽表需要唯一的样本编号和明确挑选的数值特征。注释表需要同一批编号及组别，行序可以不同。若对象跨访视反复出现，先定义本图的一列是样本还是对象与访视的组合。两表各有一条记录才能占据同一列。保留缺测单元，图中用灰底叉号标识，观测到的零仍进入数值色阶。未知的组别用据实命名的类别表示，并为它指定颜色。

不同单位的特征共用色阶前，先确定是否采用同一可解释尺度，例如逐特征使用训练集的均值和标准差得到 z 值。记录估计这些量的样本范围、变换方向和零方差特征的处理。用于展示已有标准化结果时直接读取冻结数值。表中若同时有类别、轮廓系数和特征，按数据字典显式列出特征。

PAM 的 medoid 对应实际观测，由模型给出样本 ID。从拟合结果取这些 ID。将所属组作为向量名称传入，例如 `medoid_ids = c(A = "s1", B = "s3")`，模板会逐一核对原表身份和组别归属。图注记录模型使用的距离准则。K-means 质心是计算所得的坐标，应另画质心轮廓。若要在图中展示距离质心最近的实际观测，另取对应 ID 并直接标注选样规则，保留并列处理记录。外部标签参与拟合与否写入图注。

## 使用 R 模板

下例是一个完整的模拟输入。在复制的 R 工程内运行，最后一行返回可编辑的 ggplot 对象。 [模板源码](../assets/r-template/R/plot_sample_atlas.R)

```r
source("R/plot_sample_atlas.R")
samples <- data.frame(sample_id = c("s1", "s2", "s3"),
                      x_z = c(0, NA, 1), y_z = c(-1, 0.2, 0.8))
groups <- data.frame(sample_id = c("s3", "s1", "s2"), group = c("B", "A", "A"))
plot_sample_atlas(samples, groups, features = c("x_z", "y_z"),
                  group_colours = c(A = "#C289A0", B = "#527F94"),
                  value_label = "Feature z-score", midpoint = 0)
```

传入 `sample_order` 可以采用一次确定的完整 ID 顺序，`features` 同时规定特征从上到下的展示顺序。排序按显示目的确定，例如沿用冻结的组别及组内层次聚类次序。图注说明排序依据。若有实际 medoid，可传 `medoid_ids`。分类色条沿用本套图已选的命名色值。连续量用独立色阶，设置 `midpoint` 前先确定中心值的意义。并列图应传入相同的 `limits` 和色阶端点，全部有限值都应在范围内。

验收时按图中列顺序从原表重新连接样本与注释，抽查首尾及代表样本，并核对总单元数、缺测数和代表编号。可从返回对象的 `data` 导出全部单元的 ID、特征名、数值、组别与位置。实际刊载宽度下若样本编号过密，可在图中保留代表样本标签并附上完整顺序表。
